# تحدي العائلات (Family Feud) - بالعربي

لعبة **تحدي العائلات** التفاعلية باللغة العربية، تعمل بالكامل بدون إنترنت (Offline-First) ومناسبة للاستضافة المباشرة على **GitHub Pages**.

## هيكل المجلد
- `index.html`: واجهة اللعبة (المضيف، جرس المتسابق، ووضع الجهاز الواحد).
- `style.css`: التصميم المتجاوب للهواتف والشاشات.
- `questions.js`: بنك يضم 105 سؤالاً عربياً متنوعاً مع نقاطها، منسق لسهولة التعديل والإضافة.
- `app.js`: منطق اللعبة، المؤثرات الصوتية، الربط بالبلوتوث والتزامن المحلي الفوري.
- `manifest.json` و `sw.js`: لدعم التثبيت على الشاشة الرئيسية والعمل بدون اتصال بالإنترنت.

## طريقة النشر على GitHub Pages
1. ارفع جميع الملفات الموجودة في هذا المجلد إلى مستودع جديد (Repository) على GitHub.
2. افتح **Settings** > **Pages**.
3. اختر فرع `main` ثم اضغط **Save**، وسيعمل الرابط مباشرة ويدعم التخزين المؤقت للعمل بدون إنترنت.
